Visión general

Waypoint Content OS es un CMS estructurado para que humanos y agentes trabajen sobre el mismo contrato de contenido. Está inspirado en la flexibilidad de WordPress, pero expone operaciones del dominio como herramientas tipadas.

Principio central: un agente debe operar mediante herramientas del CMS, no interpretar selectores ni raspar la interfaz.

Modelo de contenido

El núcleo soporta tipos personalizados, metadatos, taxonomías, términos, relaciones y estados de publicación. También incluye páginas visuales, plantillas y reglas de diseño.

EntryType { name: "case_study", fields: ["client", "impact", "url"], taxonomies: ["industry", "topic"] }

WebMCP

Las herramientas se registran mediante @nekuda/webmcp-sdk. El registro elimina nombres duplicados y conserva las mismas validaciones que la UI humana.

await agent.call("create_entry", { type: "case_study", title: "A better workflow", status: "published" });

El catálogo incluye contenido, taxonomías, relaciones, usuarios, plugins y editor visual.

Plugins, hooks y acciones

Los plugins se registran de forma declarativa. Los hooks reaccionan a eventos y las acciones representan operaciones ejecutables. Las pruebas locales validan el contrato sin ejecutar código arbitrario.

Despliegue

El runtime se ejecuta en Cloudflare Workers. D1 almacena el estado estructurado y R2 los archivos de Media.

npm install · npm run dev · npm test · npx wrangler deploy --config wrangler.jsonc
